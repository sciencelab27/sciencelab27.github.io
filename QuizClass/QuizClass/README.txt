QuizClass 2.1 수정본

수정 사항
- '새 방 만들기' 버튼 클릭 오류 수정
- Firebase 오류가 생기면 교사 화면 상단에 오류 내용 표시
- 학교 모니터/작은 브라우저에서 오른쪽 화면 잘림 완화
- 기존 QuizClass 2.0 기능 유지

GitHub 업데이트 방법
1. 이 ZIP의 압축을 풉니다.
2. GitHub의 QuizClass 저장소에서 기존 파일과 같은 이름의 파일들을 업로드합니다.
3. GitHub가 같은 이름 파일의 변경을 인식하면 Commit changes를 누릅니다.
4. 1~2분 뒤 기존 주소를 새로고침합니다.
5. 교사 화면에서 '새 방 만들기'를 눌러 6자리 PIN이 바뀌는지 확인합니다.
6. 오류 메시지가 뜨면 그 화면을 캡처해 주세요.

중요
- Firebase 보안 규칙은 변경하지 않았습니다.
- 현재 규칙이 quizclass_v2 경로 쓰기를 막고 있다면 화면에 권한 오류가 표시됩니다.
